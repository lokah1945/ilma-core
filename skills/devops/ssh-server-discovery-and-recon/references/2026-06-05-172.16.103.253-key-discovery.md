## Lessons Learned

1. **Format matters:** Server advertised `ssh-ed25519` support, RSA PEM keys don't work
2. **OpenSSH format keys work better:** `-----BEGIN OPENSSH PRIVATE KEY-----` format preferred
3. **Key names are misleading:** `private_key.pem` sounds canonical but isn't always the right one
4. **Host-specific binding is real:** Each VPS has different authorized_keys with different key fingerprints
5. **`.ssh/id_ed25519` might not be the "working" key:** Even if format matches, key fingerprints may differ from what's authorized
